# Scripts de développement

Installation complète du monorepo : **`docs/INSTALL.md`**.

| Fichier                           | Usage                                                                                                                   |
| --------------------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `start-dev.bat` / `start-dev.ps1` | Lance `npm run dev` depuis la **racine** du dépôt (changement de répertoire automatique). Ex. `.\scripts\start-dev.ps1` |
| `generate-icons.html`             | Ouvrir dans le navigateur pour générer/télécharger des icônes PWA ; placer les PNG dans `**public/icons/`**             |
